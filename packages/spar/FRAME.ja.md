# 継手（つぎて）

部品ではなく**骨**。既存の道具は装甲であって、これは装甲を留めるフレームにあたる。

## この機体

世界のエンジニアの仕事を戦場とし、**人がパイロットとして乗る可変機**。撃破では収束し、巡航では発散する。

禁止事項は3つ。骨の仕様はこの3行が上限を決める。

- **自環境依存を作らない** — 他人のリポジトリで、熟練者でなくても動く
- **レポートで終わらせない** — 成果物は片付いた仕事であって、記録ではない
- **形態を自動で切り替えない** — 変形はパイロットが明示的に行う

## 形態

| | 撃破（MS） | 巡航（ウェイブライダー） |
|---|---|---|
| 制御法則 | 収束（狭める・閉じる・終わらせる） | 発散（広げる・閉じない） |
| 検証 | ON | OFF |
| リミッター | ON | 緩和 |
| 台帳 | 裁定する | 記録するが裁定しない |
| 自律 | 可 | 不可 |

同じ骨に常時両方を載せると収束側が必ず勝ち、下書きに検証ゲートが掛かる。形態はそれを防ぐためだけに存在する。

## 自律

**撃破モードのみ。** 巡航は判断がパイロットの領分なので自律させる価値がない。

発火するのは次の2つに限る。

1. 人間の明示的な宣言
2. ループ／時間駆動の自動化に、**意図的に組み込まれた**とき

「なんとなく続いていた」は発火条件にならない。

## 交戦距離（撃破モードの内側）

撃破には2つの間合いがあり、規律が違う。

| | 射撃 | 接近戦 |
|---|---|---|
| 一撃 | 独立していて、間に検証を挟める | 不可分。途中で止められない |
| 対象 | 撃つ間は動かない前提でよい | **こちらが動いている間も動く** |
| 中止 | いつでも撃つのをやめられる | 踏み込んだ後は完遂か離脱のみ |
| 例 | 1回の読み取り・1回の書き込み・1回の検証 | 本番デプロイ・マイグレーション・履歴書き換え・複数ファイルに跨る改修 |

接近戦の規律は4つ。

- **踏み込む前に決める。** 中止の判断は接触前にしか存在しない。**離脱経路（巻き戻し手順）が確保できていなければ踏み込まない。**
- **間合いを詰めた瞬間に測り直す。** 事前調査の値を使わない。相手は調査の後に動いている。
- **中では検証しない。** 所見は溜め、ゲートは**離脱時**に一度だけ引く。一撃ごとに検証を挟めば当たらない。
- **リミッターは止めずに、入らせない。** 接近戦中の redline は機体を止められない。**踏み込みを拒否する**方に働く。

## 位相（4）

`出撃前` / `実行前` / `実行後` / `完了主張`

各部品は、自分がどの位相に付くかを宣言する。

## 所見

全部品が同じ形で吐く。宛先は骨ではなく**パイロット**。

| 欄 | 内容 |
|---|---|
| `phase` | 4位相のいずれか |
| `source` | どの部品か |
| `severity` | 重大度 |
| `subject` | 対象の実体（パス・URL・テーブル名） |
| `observed` | 実測値 |
| `expected` | 期待値（任意） |
| `mode` | `strike` / `cruise` / `both` |
| `actor` | 誰の手か — `agent` / `human` / `wingman`（僚機） |

## 台帳

リポジトリ内に1つ。形態によって**極性が反転する**。

- 撃破 — 終わったことを証明するための記録
- 巡航 — **捨てた案と、捨てた理由**を残すための記録

巡航側の台帳は、次の出撃前にパイロットへ手渡される。

## 停止権（2段）

- **射撃単位** — 部品が自分の一撃を拒否してよい（groundtruth が完了主張を撥ねるのはこれ）
- **出撃単位** — 有人時はパイロット、自律時は redline だけが止める

部品は具申する。機体を止めるのは部品の仕事ではない。

## 表示

- 撃破 — 重大度が高いものだけ即時。残りは台帳へ
- 巡航 — **割り込ませない。** すべて台帳へ

## 骨が創造にできること

**失わない**（捨てた案と理由を残す）／**早く閉じさせない**（巡航中は検証と停止を掛けない）。

アイデアは出さない。それは骨の機能ではない。

## 推進剤（帰投可能点）

出撃には有限の推進剤がある —— 文脈・費用・パイロットの注意力。**redline が数えるのは危険であって、残量ではない。** 安全なまま燃料切れになる。

- 骨は残量を1つ持ち、**帰投可能点**を超えたら新しい攻撃に入らない
- 超えた後にできるのは、**戦果を台帳へ書いて降りること**だけ
- 復路（結果の統合）は往路より高い。残量は往路だけで見積もらない

文脈切れで報告できずに落ちるのが、この機体の最悪の負け方になる。

## 僚機

サブエージェント・別モデル・別セッションは**僚機**であって、機体の一部ではない。

- 僚機の所見も**同じ台帳**に入る。`source` と `actor: wingman` で識別する
- 何機出すか・いつ出すかは骨の管轄外（教義であって構造ではない）
- **戻ってきた所見を、機体側で撃ち直さない**

## 脱出

台帳はセッションが死んでも残る。機体を失ってもパイロットは降りられる —— そのために台帳はリポジトリ内にある。
