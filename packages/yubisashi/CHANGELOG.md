# Changelog

## 0.1.0

### 初版：groundtruth の契約を、書き込みの前に一度指差す

groundtruth は「完了と言う前に probe で実状態を取り直す」門。この部品は同じ契約を前に引き出す。
redline が irreversible / outward / production として課金する呼び出しの直前に、まだ指差していない
契約の probe を一度走らせ、返ってきた値を「書き込み前の読み」として台帳に残す。

作った動機は台帳にある。直前の出撃で未達だった契約 5 件のうち 4 件は仕事の失敗ではなく、
**probe が走らなかった**（クォートの誤り・無いコマンド）。それが見つかるのは書き込んだ後、
ターンが止まった一番高い場所だった。鉄道の指差喚呼と同じ形の誤りなので、同じ対処を採った。
指差す＝probe を今走らせる、喚呼＝expect を先に言う。**宣言は 1 回、検査は 2 回。**

口を開くのは指が何も捉えなかったときだけ。

- 契約が無い → 先に契約を書け（置き場所を示す）
- probe が走らない（非ゼロ終了・JSON でない・`expect.type` の綴り違い）→ 今直せ
- 期待が書き込み前から真 → その契約は書き込みについて何も証明しない（1 回だけ言う）

指が本物に当たっていれば黙る。指差しは出撃ごとに契約 1 本につき 1 回。枕木ごとに指差しはしない。
操縦者が居れば助言、`AIRFRAME_AUTONOMY` の無人時は指差しの無い書き込みを deny する。
これは機体の規則であって、この部品の判断ではない。

契約の読み方は groundtruth の `contract` モジュールをそのまま使う（`@hyuga/groundtruth/contract`、
0.5.3 で公開）。読み手が 2 つあると 0.4.1 のときのように片方だけ直る。
