# Changelog

## 0.1.0

最初の公開。

1回ごとの許可確認は、10回目には意味を失う。押している側は「さっきと同じやつ」としか思わないので、
**危険なのは1回の呼び出しではなく、1セッションで積み上がった量**の方だという事実が見えない。

redline（際）は呼び出しではなく出撃を数える。本番への書き込み・不可逆な操作・依存の追加を種類ごとに
加算し、上限に達したら告げる。人が座っているセッションでは**止めずに具申する**——飛ばしているのは
パイロットで、際を越えるかどうかはその人の判断だから。止めるのは `AIRFRAME_AUTONOMY` が立っている
とき、つまり誰も座っていないときだけ。
